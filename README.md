# Nexora — AI-Powered Business Management Platform

> **Your Entire Business. One Intelligent Platform.**  
> Manage customers, sales, finances, invoices, and daily operations from one connected workspace, powered by intelligent AI.

---

## 🚀 Overview

Nexora is a modern SaaS platform designed for digital agencies, solo freelancers, consultancies, startups, and growing small businesses. It unifies operations across sales, finance, client management, and autonomous background AI agents into a single, cohesive operating system.

### Key Milestones Completed:
- **Phase 0 — Project Foundation & App Shell**:
  - Next.js 14 App Router, TypeScript, and Tailwind CSS.
  - Linear/Stripe-inspired design system with responsive sidebar, top navigation, and `⌘K` command palette.
  - Reusable atomic UI library (`Button`, `Card`, `Badge`, `Input`, `Select`, `Table`, `Modal`, `Avatar`).
- **Phase 1 — Public Marketing Landing Page**:
  - High-converting 12-section marketing website (`/`).
  - Interactive AI Copilot conversation simulator.
  - Tailored solution breakdowns for 5 industries.
  - Dynamic 4-tier pricing calculator with annual/monthly billing toggles.
  - Interactive FAQ accordion and visual dashboard preview.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Library**: [React 18](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms & Validation**: [React Hook Form](https://react-hook-form.com/) & [Zod](https://zod.dev/)
- **Data Visualization**: [Recharts](https://recharts.org/)

## 💻 Getting Started

### 1. Install dependencies:
```bash
npm install
```

### 2. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser:
- Marketing Landing Page: `http://localhost:3000/`
- Application Shell: `http://localhost:3000/app`

### 3. Build for production:
```bash
npm run build
```
